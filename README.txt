INSTRUCCIONES DE REPRODUCCIÓN

Herramienta utilizada:
Microsoft Power BI Desktop.

Fuente de datos:
Supervisión de predios estatales.

Archivos del proyecto:
- Archivo de Power BI (.pbix)
- Archivo original de datos (.xlsx)

Proceso de reproducción:
1. Abrir el archivo .pbix en Power BI Desktop.
2. Verificar la conexión con el archivo original de datos.
3. Actualizar los datos mediante Power Query.
4. Aplicar las transformaciones y limpieza realizadas.
5. Actualizar las medidas DAX.
6. Revisar los KPI, filtros y visualizaciones del informe.

Dependencias:
- Microsoft Power BI Desktop.
- Archivo original de datos utilizado en el proyecto.
